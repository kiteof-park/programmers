# 제곱근으로 약수 개수 구하기
양의 정수 `n`의 약수 개수를 Java로 구하는 방법을 정리한 학습 자료다.  

## 1. 약수란?

어떤 수를 나누었을 때 나머지가 0이 되게 하는 수다.  
예를 들어 `12 ÷ 3 = 4`이므로 3은 12의 약수다.  

```text
12의 약수: 1, 2, 3, 4, 6, 12
약수의 개수: 6개
```

Java에서는 `%`로 나머지를 구한다.  

```java
12 % 3 == 0 // true: 3은 12의 약수
12 % 5 == 0 // false: 5는 12의 약수가 아님
```

## 2. 제곱과 제곱근이란?

**제곱**은 같은 수를 두 번 곱하는 것이다.  

```text
3의 제곱 = 3 × 3 = 9
4의 제곱 = 4 × 4 = 16
6의 제곱 = 6 × 6 = 36
```

**제곱근**은 거꾸로, 같은 수 두 개를 곱해서 원래 수를 만드는 수다.  
이 자료에서는 양수인 제곱근만 생각한다.  

```text
9의 제곱근 = 3   → 3 × 3 = 9
16의 제곱근 = 4  → 4 × 4 = 16
36의 제곱근 = 6  → 6 × 6 = 36
```

제곱근이 항상 정수인 것은 아니다. 
12의 경우 `3 × 3 = 9`, `4 × 4 = 16`이므로 제곱근은 3과 4 사이에 있다.  

## 3. 왜 제곱근까지만 검사해도 될까?

핵심은 **약수가 짝으로 나온다**는 것이다.  
36을 만드는 곱셈을 작은 수부터 적어 보자.  

```text
1 × 36
2 × 18
3 × 12
4 × 9
6 × 6    ← 36의 제곱근인 6에 도착
9 × 4
12 × 3
18 × 2
36 × 1
```

`6 × 6`을 지나면 앞에서 찾은 짝이 순서만 바뀌어서 다시 나온다.  
따라서 1부터 6까지만 검사하고, 약수를 찾을 때마다 그 짝도 함께 세면 된다.  

| 검사한 수 | 나눗셈 | 찾은 약수 | 추가할 개수 |
| --- | --- | --- | --- |
| 1 | 36 ÷ 1 = 36 | 1, 36 | 2 |
| 2 | 36 ÷ 2 = 18 | 2, 18 | 2 |
| 3 | 36 ÷ 3 = 12 | 3, 12 | 2 |
| 4 | 36 ÷ 4 = 9 | 4, 9 | 2 |
| 5 | 나누어떨어지지 않음 | 없음 | 0 |
| 6 | 36 ÷ 6 = 6 | 6 | 1 |

결과는 `2 + 2 + 2 + 2 + 1 = 9개`다.
**큰 약수를 직접 검사하지 않아도, `n / 작은 약수`로 찾을 수 있다.**  

두 약수가 모두 제곱근보다 크다면 두 수를 곱한 값이 `n`보다 커진다.  
따라서 약수의 짝에는 반드시 제곱근 이하인 수가 하나 이상 있고, 그쪽만 검사해도 모든 짝을 찾을 수 있다.

### 제곱근이 정수가 아닌 12의 경우

12의 제곱근은 3과 4 사이이므로 정수는 3까지만 검사한다.

```text
12 ÷ 1 = 12 → 약수 1, 12
12 ÷ 2 = 6  → 약수 2, 6
12 ÷ 3 = 4  → 약수 3, 4
```

이렇게 약수 6개를 전부 찾는다.

## 4. Java 코드

아래 코드는 `main` 메서드 안에서 실행할 수 있는 예시다. `n`은 양의 정수여야 한다.

```java
int n = 36;
int count = 0;

for (int i = 1; i <= n / i; i++) {
    if (n % i == 0) {
        if (i == n / i) {
            count++;
        } else {
            count += 2;
        }
    }
}

System.out.println(count); // 9
```

## 5. 코드 한 줄씩 이해하기

### `int n = 36;`

약수 개수를 구할 숫자를 정한다.

### `int count = 0;`

찾은 약수가 몇 개인지 저장한다. 처음에는 0개다.

### `for (int i = 1; i <= n / i; i++)`

1부터 시작해서 제곱근까지만 검사한다.

- `int i = 1`: 검사할 수를 1로 시작한다.
- `i <= n / i`: 제곱근 이하인 동안 반복한다.
- `i++`: 검사 후 `i`를 1 늘린다.

**제곱근까지만 검사한다는 성질을 나타내는 부분은 `i <= n / i`다.**

양의 정수에서 이 조건은 `i * i <= n`과 같은 범위를 검사한다.  
제곱근을 직접 계산하지 않아도 되는 것이다.  

```text
n = 36일 때

i = 5 → 5 × 5 <= 36 → 참, 검사
i = 6 → 6 × 6 <= 36 → 참, 검사
i = 7 → 7 × 7 <= 36 → 거짓, 반복 종료
```

실제 코드에서 `i <= n / i`를 쓰는 이유는 `i * i`를 계산하다가 `int` 범위를 넘는 일을 피하기 위해서다.  
Java의 정수 나눗셈은 소수 부분을 버리지만, 양의 정수 `i`가 이 조건을 만족하는지 판별하는 데에는 문제가 없다.  

### `if (n % i == 0)`

`n`을 `i`로 나눈 나머지가 0인지 확인한다. 0이면 `i`는 약수다.

```text
36 % 4 = 0 → 4는 약수, 개수를 셈
36 % 5 = 1 → 5는 약수가 아님, 넘어감
```

### `if (i == n / i)`

찾은 약수 `i`와 짝인 약수 `n / i`가 같은지 확인한다.

```text
i = 6일 때
n / i = 36 / 6 = 6

두 약수가 모두 6이므로 같은 약수를 두 번 세면 안 됨
```

### `count++;`

짝이 같은 숫자라면 약수 개수를 1만 늘린다.

```text
6 × 6 → 서로 다른 약수는 6 하나 → 1개 추가
```

### `else { count += 2; }`

짝이 서로 다른 숫자라면 약수 개수를 2 늘린다.

```text
i = 2일 때
n / i = 36 / 2 = 18

2 × 18 → 약수 2와 18 → 2개 추가
```

**약수의 짝을 이용하는 부분은 `count += 2;`다.**

### `System.out.println(count);`

최종 약수 개수를 출력한다. 36의 경우 9가 출력된다.

## 6. 자주 헷갈리는 부분

### 종료 조건에 등호가 필요한 이유

```java
i <= n / i
```

`<`만 쓰면 36의 약수 6처럼 정확히 제곱근에 해당하는 약수를 놓친다.

### 약수를 찾을 때 항상 2개씩 더하면 안 되는 이유

`6 × 6`처럼 두 수가 같을 때는 같은 약수를 중복해서 세게 된다.
따라서 `i == n / i`인지 확인하고, 같으면 1개만 더해야 한다.

### 1의 약수 개수는?

1의 약수는 1 하나다. 위 코드는 `1 == 1 / 1`이므로 1개만 센다.

### 여러 수를 검사한다면?

각 수를 검사할 때마다 `count`를 0으로 초기화하고, 나머지 계산과 짝 계산에는 **현재 검사 중인 수**를 사용해야 한다.

## 7. 시간 복잡도

| 방법 | 검사 범위 | 시간 복잡도 |
| --- | --- | --- |
| 전체 검사 | 1부터 n까지 | O(n) |
| 절반 검사 | 1부터 n / 2까지 검사하고 자기 자신 추가 | O(n) |
| 제곱근 검사 | 1부터 제곱근 이하의 정수까지 | O(√n) |

예를 들어 `n = 1,000,000`이면 전체 검사는 100만 번, 제곱근 검사는 1,000번의 반복으로 약수 개수를 구할 수 있다.
추가 배열 없이 변수만 사용하므로 공간 복잡도는 O(1)이다.

## 8. 기억할 핵심

1. 약수는 `i`와 `n / i`가 짝으로 나온다.
2. `i <= n / i`를 조건으로 쓰면 제곱근까지만 검사한다.
3. 약수를 찾으면 보통 2개를 더한다.
4. 두 약수가 같으면 1개만 더한다.

| n | 약수 개수 |
